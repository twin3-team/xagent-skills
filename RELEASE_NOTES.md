# xAgent ID Skill 0.2.0

Adds `checkout-link`: for a website owner, confirm a plan is currently sellable and return the xagent.id claim link prefilled with their domain and plan, plus the price and buyer steps. The owner proves domain control and pays in Stripe Checkout in their own browser. The helper starts no claim, makes no payment and grants no entitlement.

Public lookups are unchanged: company Agent Cards by domain, pricing, billing boundaries, health and installation readiness. No credential is needed.

The ZIP includes the complete skill directory, client helper, API reference, client metadata, MIT license and notice. SHA256SUMS and release.json bind the archive to this workflow's source commit.

Company registration resolution is upstream-dependent and may return 503. MCP readiness does not constitute signature verification or install the MCP server. Marketplace approval, ownership, endorsement, ranking and recommendation are not asserted.
