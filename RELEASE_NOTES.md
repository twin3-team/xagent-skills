# xAgent ID Skill 0.1.0

Read public company Agent Cards by domain, preserve evidence and unknown lifecycle states, and inspect pricing, billing, health and installation readiness. No credential is needed for public lookups.

The ZIP includes the complete skill directory, client helper, API reference, client metadata, MIT license and notice. SHA256SUMS and release.json bind the archive to this workflow's source commit.

Company registration resolution is upstream-dependent and may return 503. MCP readiness does not constitute signature verification or install the MCP server. Agent installer compatibility has been checked separately from full model task behavior. Marketplace approval, ownership, endorsement, ranking and recommendation are not asserted.
